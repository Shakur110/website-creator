# Daily blog calendar

One new article goes live every day from this list.

A scheduled task runs daily. It keeps about a week of articles written ahead: it takes the `planned` rows
in order, writes each article into `src/lib/posts.ts` with that row's date, and changes the status to
`scheduled`. The website only shows a post once its date arrives, so each article appears on its own day.

Edit freely: change titles, reorder rows or add rows at the bottom. A row already `scheduled` has been
written; edit it in `src/lib/posts.ts` instead.

Going live: Lovable publishes snapshots. Click Publish → Update in Lovable at least once a week so the
live site holds the next week's articles.
